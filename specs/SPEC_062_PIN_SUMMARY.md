# SPEC 062 — 핀 요약 갱신

> 2026-11-26 사람 「둘다지금」(브리핑 선택 2: 핀 요약 갱신하기). 야간 10회차 발견: 요약은 노트를 처음 만들 때만 쓰임.

## 1. 목표
`src/services/noteMarkdown.ts` `buildNoteMarkdown`은 「## 📌 집중 분석 핀(Unclear Spots) 요약」 아래에 핀 목록을 쓰지만, 이후 저장(`replaceSessionBlock`)은 세션 블록·frontmatter만 바꿔 핀을 꽂거나 빼도 요약이 처음 그대로다. 저장할 때 이 절 내용을 지금 핀 목록으로 바꾼다. 하지 않을 것: 요약 줄 모양·문구 바꾸기, 다른 절 건드리기.

## 2. 파일
- 수정 `src/services/noteMarkdown.ts`: 핀 요약 줄 만들기를 함수로 빼고(`buildNoteMarkdown`과 같은 글), `replaceSessionBlock`이 절을 바꿈.
- 수정 `tests/fixtures/` 의 Test 41 데이터(러너는 필요할 때만 최소한).

## 3. 정의
- 절 = 줄 `## 📌 집중 분석 핀(Unclear Spots) 요약` 다음 줄부터, 그 뒤 처음 나오는 `## `로 시작하는 줄(또는 세션 블록 머리 ```ear-coach-session) 바로 앞까지. 그 안을 지금 요약 줄(핀 없으면 지금의 안내 한 줄) + 빈 줄 하나로 바꾼다.
- 제목 줄이 없으면(사람이 지움) 아무것도 더하지 않는다. 제목 줄이 두 개 이상이면 첫 번째만.
- 사람이 요약 절 **밖**에 쓴 글은 한 글자도 안 바뀐다. 요약 절 안은 앱이 관리하는 곳(사람 글이 있으면 덮임 — 원래 설계와 같음).
- 같은 세션으로 두 번 바꿔도 결과 같음(멱등).

## 4. 범위 밖
요약 줄 문구·모양, 노트 제목·안내 글, 사운드 해부 기록 절, 이미 만든 노트를 한꺼번에 고치기(다음 저장 때 저절로 갱신).
